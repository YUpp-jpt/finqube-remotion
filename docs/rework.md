# 动作与空间重建

新版针对上一版缺少空间镜头、引导轨迹错误、文字过平和卡片比例偏差重新构建。

原视频与[用户提供的效果模板](https://github.com/guangjun5952/motionface-finqube-full-template/tree/c4596775118fedd270c48c3415133295156d708c)用于画面和方法分析；当前代码自行重绘。源视频、模板音轨与模板源文件未进入该公开仓库。

## 改动

- 全片共享透视世界，在入镜时产生纵深、旋转与错相回稳；稳定时维持轻微相机漂移。
- 文字以逐词延迟、弹性越过基线、倾斜和缩放进入，恢复 3 秒处 Creator 的重新弹入。
- 荧光引导轨迹由参考中的颜色阈值、前端方向与尾迹位置测量重建；尾迹和头部伸缩随速度变化。
- 财务卡片恢复正确长宽比例，标题附着于卡片坐标，保持单行和错峰入场。
- 19–25 秒独立空间摄像机沿收入、发票、交易巡游，分轴启动、急行、刹车和侧倾持续发生。
- 先从源码生成该段普通投影帧，再做浮点 WebGL 径向采样；中间文件可重复生成，不分发参考视频帧。
- 背景加入六层移动光团和扫光；财务巡游的光场还响应相机位移与速度。
- 周边卡片按真实深度环绕，恢复价格卡进入时的透视与回弹；免费段采用原生彩色表情。

## 核查范围

本地保存了原片与新版同帧对照、财务巡游镜片图，以及整片同步对照视频。关键镜头包括 F45、F810、F1230、F1296、F1356、F1440、F1545 与 F2130。判断依据是实际画面位置、比例、曲率和时序采样，不以渲染成功作为相似度证明。

自动检查负责视频尺寸、帧率、帧数、时长、编解码和完整解码。逐像素一致、原配乐复现、完整人工试听不在已验证范围内。
